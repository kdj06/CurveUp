    2. Clean: Spark turns the raw file into trusted data
    

    02_clean.scala reads the raw zone with a fixed schema, fixes the timestamps, removes test rows, and writes Parquet to the clean zone, one folder per chatbot.
    

    rawcleandropped
    

    

    

    What the cleaning step does
      

    • Reads the JSON with an explicit schema, so a field can't change type between exports
      • 

    • Drops the test thread (2 rows with no programme) and any duplicate messages
      • 

    • Turns the text time into a UTC timestamp, plus date, month and hour
      • 

    • Labels each sender as user, bot or staff (staff = a human replying from the dashboard)
      • 

    • Computes the bot reply time with a window function (lag)
      • 

    • Sends any row with a bad timestamp to the rejects zone (there were 0)
      •

    What CurveUp told us
    

    "The low confidence FAQ answers and longer waits for staff replies are especially useful for us to look into."
    

    They also asked which FAQs most often led to low-confidence answers, and whether the long staff waits happen at particular times or around programme events. The warehouse can answer both with one more query each.
